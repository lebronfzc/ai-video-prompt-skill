# AI 视频提示词 Skill

这个 skill 用于把故事、创意描述、参考视频拆解需求或镜头想法，整理成可以直接复制到 AI 视频生成工具中的中文视频提示词。

## 使用方法

在支持 Codex Skill 的环境中，使用 `$ai-video-prompt` 调用：

`使用 $ai-video-prompt，把剑魔和天使在废墟圣殿中战斗的故事，整理成一段 18 秒的超写实电影级视频提示词。`

也可以补充以下信息，让结果更贴合需求：

- 故事主题和人物关系
- 视频总时长或每个镜头的时长
- 人物外观、服装和武器
- 场景地点、时代、天气和光线
- 画面风格、色彩和参考作品
- 希望出现或禁止出现的内容

如果没有提供完整信息，skill 会在不改变故事方向的前提下，合理补全人物、场景、动作、镜头和画质细节。

## 可以得到什么结果

输出是一份可直接复制使用的中文视频提示词，固定包含：

1. **【基础设定】**：逐一描述角色的外观、服装、标志性特征和身份，保证后续分镜中的角色保持一致。
2. **【氛围与画质】**：包含电影级质感、超写实、极致逼真、Photorealism（真人实景拍摄），并补充色彩、光线、材质、景深和整体视觉基调。
3. **【画面内容】**：按时间顺序拆分分镜，每个分镜包含起止秒数、景别、构图、运镜手法、人物动作、环境变化和事件结果。
4. **限制描述**：限制字幕、文字、水印、Logo、人物崩坏、五官漂移、肢体错误、道具消失、场景闪烁和镜头跳帧等常见问题。

例如，输入“剑魔和天使打架”，可以得到包含角色设定、史诗奇幻画质、0 到 18 秒连续分镜、推拉摇移运镜、武器交击结果，以及无字幕和人物稳定性限制的完整提示词。这个 skill 负责生成提示词文本，不直接生成或渲染视频。

## 推荐输入格式

`使用 $ai-video-prompt` + `主题/故事` + `人物设定` + `视频时长` + `画面风格` + `特殊限制`
