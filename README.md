# AI 视频提示词 Skill

把故事、创意、画面需求或已读取的参考素材，整理成可直接复制到 AI 视频生成工具中的中文分镜提示词。此 skill 生成提示词文本，不直接生成或渲染视频，也不用于静态图片提示词。

当前规范同步日期：2026-10-08。执行规则以 [SKILL.md](SKILL.md) 为准。

## 一张图看懂提示词框架

![AI 视频提示词框架：基础设定、氛围与画质、画面内容和结尾限制](assets/prompt-framework.svg)

输出固定为三个一级栏目，最后追加“限制描述：”段落。图中的说明文字用于帮助理解，实际输出不额外添加说明栏目。

| 部分 | 要回答的问题 | 必须写清什么 |
| --- | --- | --- |
| 【基础设定】 | 谁出现在画面里？ | 每个反复出现角色的身份、年龄感、性别表现、脸部、发型、体型、服装、颜色、显著标记 |
| 【氛围与画质】 | 整体看起来是什么感觉？ | 默认写实画质词，以及匹配故事的色彩、光线、材质、景深、天气、时代感 |
| 【画面内容】 | 每段时间拍什么、怎么拍？ | 连续起止秒数、景别、构图、运镜顺序与目的、动作、互动、环境变化、结果 |
| 限制描述： | 哪些内容和错误要避免？ | 无字幕、无音乐、仅音效、无画面文字，以及人物、道具、场景和镜头稳定性 |

## 安装与调用

将本仓库下载后，把包含 SKILL.md 和 agents 文件夹的目录命名为 ai-video-prompt，放进你的 Codex skills 目录（通常为 ~/.codex/skills/ai-video-prompt）。assets 和 README.md 可一并保留，供查看图解和说明。

在能够读取此 skill 的环境中输入：

> 使用 $ai-video-prompt，把一个穿黄色雨衣的女孩在雨巷里找到走失小狗的故事，整理成一段 12 秒的超写实电影级视频提示词。

推荐输入形式：

> 使用 $ai-video-prompt。故事：……；角色：……；时长：……；场景：……；视觉风格：……；必须出现：……；禁止出现：……。

可以只给一句故事。未指定总时长时，会按剧情复杂度合理分配；信息不足但不影响故事方向时，会合理补全。只有缺失内容会明显改变故事方向或无法识别参考素材时，才会询问。

使用参考视频或图片时，提供可实际读取的素材，并说明想参考构图、节奏、色彩还是光线。skill 只提炼实际读取到的内容，不会声称看过无法读取的素材。

## 当前使用规范

- **直接交付成品**：简体中文，不附创作思路、分析过程、开场说明或结尾建议，不用 Markdown 代码块。
- **保留用户设定**：不改变明确指定的角色、剧情、风格、时长和限制，不改变故事核心。
- **人物与空间连续**：角色的脸、发型、体型、服装、颜色和身份保持一致；变化须交代发生的分镜与过程。道具的外观、尺寸、颜色、位置和空间关系保持连续。
- **默认画质**：包含“电影级质感、超写实、极致逼真、Photorealism（真人实景拍摄）”，补充具体视觉基调，风格词须兼容。
- **分镜时间连续**：每个镜头都有起止秒数，前后不重叠、不留空档。镜头数量按故事需要安排。
- **每镜字段完整**：景别、构图、运镜手法、画面内容缺一不可。构图交代主体位置、前中后景、视线方向和画面重点。
- **运镜有目的**：可用推、拉、摇、移、跟拍、环绕、升降、手持等组合，但要交代先后顺序与叙事目的。
- **动作可拍摄**：用动作、表情和互动表现情绪，写出事件结果或镜头落点，避免抽象心理描写。
- **相邻镜头能衔接**：人物朝向、动作、视线、道具、空间和光线方向连续，避免瞬移、穿帮、无原因换装或场景突变。
- **声音与文字**：不添加音乐、配乐、旁白或台词栏目；仅按动作补充必要音效。有对话情境时只描述表情、口型与动作，不生成画面文字。
- **结尾限制完整**：所有分镜后追加“限制描述：”。始终保留无字幕、无画面文字和人物稳定性要求；其他限制按故事补充，用户明确允许某种效果时可移除对应限制。

这些规则约束的是提示词输出，无法保证下游视频模型完全遵循。

## 完整输出示例

以下展示上面“雨巷找小狗”的输出形式；角色和镜头仅为示例，不是固定模板内容。

【基础设定】  
角色女孩：约 10 岁，女性外观，圆脸、黑色齐耳短发，身形瘦小，穿亮黄色带帽雨衣、深蓝长裤、白色雨靴，左手腕有红色细绳。  
角色小狗：幼年棕白色短毛犬，体型小，圆眼、下垂耳，胸前白毛，佩戴无文字的红色项圈。

【氛围与画质】  
电影级质感、超写实、极致逼真、Photorealism（真人实景拍摄）。现代城市雨巷，阴天柔和冷光从画面左上方照入，黄色雨衣形成暖色焦点；湿润砖墙与石板路保留真实纹理，地面积水呈现自然倒影，浅景深突出女孩与小狗。

【画面内容】  
分镜 1：0秒到4秒  
景别：全景。  
构图：女孩位于左侧前景，向画面右侧前进；右侧中景是一只倒扣的木箱，小狗蜷在木箱旁；后景巷道延伸。  
运镜手法：先向右平移跟随女孩，再缓慢推近，突出她发现小狗后停步的动作。  
画面内容：女孩从左向右沿巷道走来，雨靴踩出细小水花；她转头看见木箱旁的小狗，停在它左侧约一米处，身体朝向右侧。音效为雨声与踩水声。

分镜 2：4秒到8秒  
景别：中景。  
构图：保持女孩在左、小狗在右；木箱位于小狗后方，女孩视线落向右下方的小狗。  
运镜手法：镜头缓慢下降至小狗视线高度，呈现女孩蹲下接近的过程。  
画面内容：女孩原地蹲下，将带红绳的左手缓缓伸向小狗鼻前；小狗探头闻她的手指，随后向左迈出一步，鼻尖轻触她的掌心。音效为雨声与轻微爪步声。

分镜 3：8秒到12秒  
景别：近景。  
构图：女孩在左、小狗在右，左手与小狗头部位于画面中央；后方木箱与砖墙虚化。  
运镜手法：缓慢推近至手掌与小狗头部，镜头落在轻抚动作上。  
画面内容：承接鼻尖接触掌心的动作，女孩慢慢翻转左手，轻抚小狗额头，露出微笑；小狗保持站位，抬头靠近她，尾巴轻摆。音效为雨声、衣料摩擦声与轻微犬呜声。

限制描述：一定不需要字幕、一定不要音乐、只要音效、禁止人物崩坏、禁止任何文字/标题/标识/水印/Logo/乱码，禁止五官漂移、脸部变形、身份变化、服装突变、多余或缺失肢体、手指畸形、身体穿模、道具凭空出现或消失、场景结构闪烁或改变；禁止无关人物、错误时代物件、风格突变、镜头抖动、闪烁、跳帧、背景变形和小狗外观突变。
